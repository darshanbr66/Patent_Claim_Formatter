# Patent Claim Formatter

A modern, enterprise-grade frontend application for uploading, processing, viewing, and downloading formatted patent claim documents.

## Overview

Patent Claim Formatter is a production-ready React application designed to integrate with a backend document processing service.

The application allows users to:

- Upload patent documents
- Validate supported file formats
- Process documents through backend APIs
- View formatted patent claims
- Download processed documents (PDF initially, DOCX later)

The frontend is designed to be scalable, reusable, and easy to integrate with future backend services.
